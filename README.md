# Configurable AXI4-Lite / AXI4-Stream Based FPGA Processing IP Core

##  Project Overview

This project focuses on the design and simulation of a configurable FPGA Processing IP Core using **Verilog/SystemVerilog** with **AXI4-Lite** and **AXI4-Stream** interfaces.

The AXI4-Lite interface is used for configuration and control, while the AXI4-Stream interface is used for streaming data transfer. The design was developed and verified using **Xilinx Vivado** through RTL simulation, waveform analysis, and bitstream generation.

##  Objectives

* Design a configurable FPGA Processing IP Core.
* Implement AXI4-Lite for control and configuration.
* Implement AXI4-Stream for data transfer.
* Verify the design through RTL simulation.
* Analyze simulation waveforms.
* Generate the FPGA bitstream using Vivado.

##  Tools & Technologies

* Verilog / SystemVerilog
* Xilinx Vivado
* AXI4-Lite
* AXI4-Stream
* RTL Simulation
* FPGA Design Flow


##  Verification

The design was verified using RTL simulation in Vivado. Simulation waveforms were analyzed to check the behavior of the interfaces and processing logic.

##  Bitstream Generation

The designed project was taken through the Vivado FPGA design flow and a bitstream was generated.

> **Note:** The generated bitstream was not physically deployed or tested on an FPGA development board.
